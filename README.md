## 1. AI Personal Assistant

**Tech:** Python, Speech Recognition, NLP

## 2. Energy Consumption Analyzer

A data analysis system that analyzes appliance-level electricity usage and visualizes patterns using statistical analysis and regression models.

**Tech:** Python, Pandas, NumPy, Plotly

## 3. Cricket Data Analyzer

A sports analytics project that analyzes IPL datasets to extract insights about teams, players, and match performance.

**Tech:** Python, Pandas, Matplotlib

---

## 4. DocumentMind – AI PDF Question Answering System

An AI-powered document assistant that allows users to upload PDF files and ask questions about the document using **Retrieval-Augmented Generation (RAG)**.

**Features**

* Upload PDF documents
* Ask natural language questions
* AI retrieves relevant information from documents
* Context-aware responses

**Tech:** Python, LangChain, Vector Databases, OpenAI API

---

## 5. SafeLink – AI Link & File Security Analyzer

A cybersecurity-focused tool that analyzes URLs and uploaded files to determine whether they are safe or potentially malicious.

**Features**

* URL safety detection
* File and PDF analysis
* Risk scoring system

**Tech:** Python, Security APIs

---

## 6. Smart Ambulance Routing System

A smart navigation system designed to help ambulance drivers reach hospitals faster by calculating optimized routes and estimating travel time.

**Features**

* Nearby hospital detection
* Multiple route comparison
* Traffic signal estimation
* Google Maps navigation integration
* Built-in chatbot assistance

**Tech:** Google Maps API, Location Services, AI Chatbot

## 7. FridgeChef – AI Recipe Generator

A smart cooking assistant that generates recipes based on ingredients available at home.

Users can also enter the name of a dish to receive step-by-step cooking instructions and ingredient quantities.

**Tech:** Python, AI APIs, NLP

## 8. AI Agent using n8n + ChatGPT

An AI-powered disaster response system that analyzes **images, text, and videos** to assess disaster severity, detect victims, and provide real-time rescue guidance.
